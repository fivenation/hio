# Блочная система: Техническая документация

## 1. Система координат

### 1.1. Мировые координаты
- **X, Y** — горизонтальная плоскость (метры)
- **Z** — вертикальная ось (метры)
- Игрок всегда находится на уровне **Z = 0**

### 1.2. Диапазон высот

| Уровень | Значение |
| --- | --- |
| Z_min | -3 |
| Z_max | +4 |
| Всего уровней | 8 |

### 1.3. Преобразование координат

```
blockX = floor(worldX)
blockY = floor(worldY)
blockZ = floor(worldZ)
blockIndexZ = blockZ - Z_min   // 0..7 для доступа в массиве
```

## 2. Блок (Block)

### 2.1. Определение
Блок занимает объём **1×1×1 метр** в пространстве. Каждый блок имеет уникальный идентификатор и набор текстур для шести граней.

### 2.2. Структура данных блока

```dart
class Block {
  /// Уникальный идентификатор типа блока (0 = Air)
  final int id;
  
  /// Проходимость на уровне Z = 0
  /// true = блок непроходим
  /// false = можно пройти
  final bool isSolid;
  
  /// Текстуры для каждой грани
  final BlockTextures textures;
}

class BlockTextures {
  final Rect top;      // +Z (верхняя грань)
  final Rect bottom;   // -Z (нижняя грань)
  final Rect north;    // +Y
  final Rect south;    // -Y
  final Rect east;     // +X
  final Rect west;     // -X
}
```

### 2.3. Типы блоков

| ID | Название | isSolid | Описание |
| --- | --- | --- | --- |
| 0 | Air | false | Пустота, не рендерится |
| 1 | Solid | true | Твёрдый блок (камень, дерево, кирпич) |
| 2..65535 | Reserved | — | Зарезервировано для будущих типов |

### 3.1. Файл определения блока (JSON)

```json

    "east": [0, 0, 1, 1],
    "west": [0, 0, 1, 1]
  }
}
```

### 3.2. Формат UV-координат
- Массив из 4 чисел: `[left, top, right, bottom]`
- Значения от 0.0 до 1.0
- Относительно текстуры-атласа

## 4. Текстурный атлас

### 4.1. Параметры атласа

| Размер текстур | Разрешение атласа | Ячеек (16×16) | Использование |
| --- | --- | --- | --- |
| 128 px | 2048×2048 | 256 | High quality |
| 64 px | 1024×1024 | 256 | Medium quality |
| 32 px | 512×512 | 256 | Low quality |

### 4.2. Организация ячеек
- Ячейка 0: не используется (Air)
- Ячейка 1: камень
- Ячейка 2: дерево
- Ячейка 3: кирпич
- Ячейка 4..255: зарезервированы

### 4.3. Вычисление UV координат

```
cellX = (id - 1) % 16
cellY = (id - 1) ~/ 16

left   = cellX / 16.0
top    = cellY / 16.0
right  = (cellX + 1) / 16.0
bottom = (cellY + 1) / 16.0
```

## 6. Рендеринг блоков

### 6.1. Алгоритм

1. Определить область рендеринга: `[player.x - R, player.x + R] × [player.y - R, player.y + R]`
2. Для каждого `(x, y)` в области:
   - Для каждого `z` в диапазоне `[zMin, zMax]`:
     - Получить ID блока
     - Если ID == 0 → пропустить
     - Для каждой из 6 граней проверить видимость
     - Если грань видима → вычислить проекцию и отрисовать

### 6.2. Видимость грани

Грань видима, если соседний блок с этой стороны имеет ID == 0 (Air).

### 6.3. Оптимизация по расстоянию

| Расстояние | Режим рендеринга |
| --- | --- |
| 0–16 м | Текстура 128×128 |
| 16–32 м | Текстура 64×64 (mipmap) |
| 32–48 м | Текстура 32×32 (mipmap) |
| 48–64 м | Туман (смешивание с цветом неба) |
| >64 м | Не рендерится |

## 7. Освещение

### 7.1. Глобальное освещение
- Единое значение `ambientLight` для всей сцены
- Применяется как множитель к цвету текстуры

### 7.2. Динамическое освещение
- Источники света имеют позицию, радиус, интенсивность
- Для каждого блока рассчитывается суммарное влияние всех источников
- Затухание: `factor = 1 - distance / radius`

### 7.3. Формула итогового цвета

```
finalColor = textureColor × (ambientLight + sum(dynamicLight))
```

## 8. Коллизии

### 8.1. Правила
- Проверка только на уровне Z = 0
- Блок с ID = 0 → проходим
- Блок с ID > 0 → непроходим
- Границы карты → непроходимы

### 8.2. Алгоритм

```dart
bool canMoveTo(x, y, radius) {
  minX = floor(x - radius)
  maxX = floor(x + radius)
  minY = floor(y - radius)
  maxY = floor(y + radius)
  
  for ix in minX..maxX:
    for iy in minY..maxY:
      if ix < 0 or ix >= width or iy < 0 or iy >= height:
        return false
      if getBlockId(ix, iy, 0) != 0:
        return false
  return true
}
```

## 9. Тестовая карта

### 9.1. Параметры
- Размер: 70×70 блоков по X и Y
- Диапазон Z: от -3 до +4
- Игрок стартует в центре: X=35, Y=35, Z=0

### 9.2. Структура карты

**Уровень Z = 0 (уровень игрока):**
- Квадратная комната 20×20 блоков в центре
- Стены толщиной 1 блок по периметру комнаты
- Внутри комнаты: 4 колонны (блоки Solid) по углам внутреннего квадрата 10×10
- Остальное пространство (за пределами комнаты) — Air

**Уровни Z = 1, 2, 3:**
- Стены комнаты продолжаются вверх
- Колонны продолжаются вверх
- Остальное — Air

**Уровень Z = 4 (потолок):**
- Сплошной потолок над комнатой (Solid)
- Над колоннами — тоже потолок

**Уровни Z = -1, -2, -3 (подземелье):**
- Сплошной пол на Z = -1 (Solid) под всей комнатой
- На Z = -2 и Z = -3 — Air

### 9.3. Генерация карты (псевдокод)

```python
def generate_test_map(width=70, height=70):
    room_size = 20
    room_start = (width - room_size) // 2
    room_end = room_start + room_size
    
    blocks = []
    
    # Z = 0
    for x in range(width):
        for y in range(height):
            # Стены комнаты
            if (x == room_start or x == room_end-1 or 
                y == room_start or y == room_end-1):
                if room_start <= x < room_end and room_start <= y < room_end:
                    blocks.append([x, y, 0, 1])
            
            # Колонны (внутри комнаты)
            elif (x == room_start+5 or x == room_end-6) and \
                 (y == room_start+5 or y == room_end-6):
                blocks.append([x, y, 0, 1])
    
    # Z = 1,2,3 (стены и колонны)
    for z in [1, 2, 3]:
        for x in range(room_start, room_end):
            for y in range(room_start, room_end):
                # Стены
                if (x == room_start or x == room_end-1 or 
                    y == room_start or y == room_end-1):
                    blocks.append([x, y, z, 1])
                
                # Колонны
                elif (x == room_start+5 or x == room_end-6) and \
                     (y == room_start+5 or y == room_end-6):
                    blocks.append([x, y, z, 1])
    
    # Z = 4 (потолок)
    for x in range(room_start, room_end):
        for y in range(room_start, room_end):
            blocks.append([x, y, 4, 1])
    
    # Z = -1 (пол подвала)
    for x in range(room_start, room_end):
        for y in range(room_start, room_end):
            blocks.append([x, y, -1, 1])
    
    return blocks
```
