# Блочная система

## 1. Система координат

### 1.1. Мировые координаты

- **X, Y** — горизонтальная плоскость (метры)
- **Z** — вертикальная ось (метры)
- Игрок находится на уровне **Z = 0** (камера на высоте 1.5)

### 1.2. Диапазон высот


| Уровень       | Значение |
| ------------- | -------- |
| Z_min         | -3       |
| Z_max         | +4       |
| Всего уровней | 8        |


### 1.3. Преобразование координат

```
blockX = floor(worldX)
blockY = floor(worldY)
blockZ = floor(worldZ)
zIndex = blockZ - Z_min   // 0..7 для доступа в массиве
```

**Реализация:** `WorldMap` (`world_map.dart`) — методы `getBlockId`, `setBlockId`

## 2. Блок (Block)

### 2.1. Определение

Блок занимает объём **1×1×1 метр**. Каждый блок имеет уникальный ID и набор текстур для шести граней.

### 2.2. Структура


| Компонент | Описание                           | Класс/Файл              |
| --------- | ---------------------------------- | ----------------------- |
| ID        | Уникальный идентификатор (0 = Air) | `BlockDefinition`       |
| isSolid   | Проходимость на уровне Z = 0       | `block_definition.dart` |
| textures  | UV-координаты для 6 граней         | `BlockTextures`         |
| color     | Fallback цвет (если нет текстур)   | `block_definition.dart` |


### 2.3. Типы блоков


| ID       | Название | isSolid | Описание               |
| -------- | -------- | ------- | ---------------------- |
| 0        | Air      | false   | Пустота, не рендерится |
| 1..65535 | —        | —       | Загружаются из JSON    |


**Регистрация:** `BlockRegistry` (`block_registry.dart`) — `register()`, `get()`

## 3. Формат хранения

### 3.1. Файл определения блока

**Путь:** `resources/data/blocks.json`

```json
{
  "blocks": [
    {
      "id": 1,
      "name": "stone",
      "isSolid": true,
      "textures": { "all": [0.0, 0.0, 0.0625, 0.0625] }
    }
  ]
}
```

**Загрузчик:** `BlockLoader.loadAllBlocks()`

### 3.2. UV-координаты

- Массив из 4 чисел: `[left, top, right, bottom]`
- Значения от 0.0 до 1.0 (относительно атласа)
- Хранится в `RectUV` (`rect_uv.dart`)

### 3.3. Текстурный атлас


| Размер текстур | Разрешение атласа | Ячеек (16×16) |
| -------------- | ----------------- | ------------- |
| 128 px         | 2048×2048         | 256           |
| 64 px          | 1024×1024         | 256           |
| 32 px          | 512×512           | 256           |


**Управление:** `TextureAtlasManager` (`texture_atlas.dart`) — `loadAllAtlases()`, `getAtlas()`

## 4. Рендеринг блока

### 4.1. Процесс рендеринга (один кадр)

```
┌─────────────────────────────────────────────────────────────┐
│  WorldRenderer.render()                                      │
│  ├── Обновление камеры (_camera.updateCache)                │
│  ├── Очистка кэшей (_columnCache, _allFaces)                │
│  ├── Обход области видимости (x: startX..endX)              │
│  │   └── Обход колонок (y: startY..endY)                    │
│  │       └── Обход высот (z: zMin..zMax)                    │
│  │           └── _collectBlockFaces() для каждого блока     │
│  ├── Сортировка граней по глубине (buckets)                 │
│  └── Отрисовка каждой грани → FaceRenderer.render()         │
└─────────────────────────────────────────────────────────────┘
```

**Класс:** `WorldRenderer` (`world_renderer.dart`)

### 4.2. Сбор граней блока

Для каждого блока проверяются 6 граней. Грань видима, если **соседний блок = Air**.

```dart
// world_renderer.dart — _collectBlockFaces()
// Север: northAir = _isFaceVisible(x, y+1, z)
// Юг:   southAir = _isFaceVisible(x, y-1, z)
// Восток:eastAir  = _isFaceVisible(x+1, y, z)
// Запад: westAir  = _isFaceVisible(x-1, y, z)
// Верх:  topAir   = _isFaceVisible(x, y, z+1)
// Низ:   bottomAir= _isFaceVisible(x, y, z-1)
```

### 4.3. Порядок вершин грани

Все грани используют единый порядок относительно камеры:


| Индекс | Позиция        | UV              |
| ------ | -------------- | --------------- |
| 0      | левый нижний   | (left, bottom)  |
| 1      | правый нижний  | (right, bottom) |
| 2      | правый верхний | (right, top)    |
| 3      | левый верхний  | (left, top)     |


**Координаты вершин для каждой грани** — см. `world_renderer.dart` → `_collectBlockFaces()`

### 4.4. Отрисовка грани

```dart
// face_renderer.dart — render()
// 1. Определение LOD по расстоянию
// 2. Получение текстуры из атласа
// 3. Создание Vertices (4 точки, UV, indices [0,1,2, 0,2,3])
// 4. canvas.drawVertices()
```

### 4.5. LOD (Level of Detail)


| Расстояние | LOD    | Размер текстуры |
| ---------- | ------ | --------------- |
| 0–8 м      | high   | 128px           |
| 8–16 м     | medium | 64px            |
| 16–32 м    | low    | 32px            |
| 32–48 м    | fog    | туман           |
| >48 м      | none   | не рисуется     |


**Класс:** `TextureLODManager` (`texture_lod.dart`) — `getLOD()`, `getTexturePaint()`

## 5. Камера и проекция

### 5.1. Параметры камеры


| Параметр           | Значение |
| ------------------ | -------- |
| FOV (вертикальный) | 60°      |
| minDepth           | 0.05     |
| Высота камеры      | 1.5 м    |


### 5.2. Проекция точки

```dart
// camera.dart — worldToScreen()
// 1. Вычисление глубины: forwardDepth = dot(point - player, forward)
// 2. depth = max(forwardDepth, minDepth)
// 3. screenX = width/2 + (rightOffset / depth) * scale
// 4. screenY = height/2 - (upOffset / depth) * scale
```

### 5.3. Кэширование проекций

- Кэш живёт **1 кадр** (`_currentFrameId`)
- Ключ: округленные координаты + ID кадра
- Очищается в `updateCache()`

## 6. Освещение

### 6.1. Глобальное освещение

- Единое значение `ambientLight` для всей сцены
- Применяется как множитель к цвету текстуры

### 6.2. Динамическое освещение

```dart
// lighting.dart — LightSource
// Вклад в точке: intensity * (1 - distance/radius)
// Итоговая яркость: clamp(ambientLight + sum(вклады), 0.0, 1.0)
```

## 7. Коллизии

### 7.1. Правила

- Проверка на уровне Z = 0 (уровень игрока)
- Блок с ID = 0 → проходим
- Блок с ID > 0 → непроходим
- Радиус коллизии камеры: 0.3 м

### 7.2. Алгоритм

```dart
// game_world.dart — canMove()
// 1. Определение области пересечения (x ± radius, y ± radius, z ± radius)
// 2. Для каждого блока в области:
//    - Нахождение ближайшей точки в блоке к центру камеры
//    - Проверка расстояния < radius²
// 3. Если есть пересечение → движение запрещено
```

**Класс игрока:** `Player` (`player.dart`) — `updatePosition()`, `_resolveCollision()`

## 10. Диагностика

### 10.1. FpsCounter

Отображает:

- FPS (текущий / средний)
- Время кадра
- Количество граней в кадре
- Размер кэшей шейдеров и колонок
- Предупреждения (низкий FPS, слишком много граней)

**Класс:** `FpsCounter` (`fps_counder.dart`) — `update()`, `updateMetrics()`, `render()`

### 10.2. Мини-карта

Отображается в правом верхнем углу:

- Блоки на уровне Z = 0
- Позиция и направление игрока

**Класс:** `Minimap` (`minimap.dart`) — `render()`
